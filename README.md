# Ival Permana — Portfolio

Personal portfolio website showcasing full-stack web applications, mobile software, and AI-powered products.

## Overview

A modern, minimalist portfolio application built with high-performance dark void aesthetics, interactive CLI developer tools, dynamic project showcases, and full bilingual (ID / EN) support.

## Tech Stack

- **Core:** React, Vite
- **Styling:** Tailwind CSS
- **Architecture:** Modular Component System
- **Internationalization:** Native Context i18n
